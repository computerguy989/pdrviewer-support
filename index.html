PDR Viewer

A Mac and iPad app for reviewing GM Performance Data Recorder telemetry from track days — lap comparison, video sync, corner-by-corner analysis, and vehicle stats.

Get help

Questions, bug reports, and feature requests: computerguy989@gmail.com

The app can generate a diagnostic report for you — open Report a Bug from the toolbar, describe what happened, tap Generate report, then attach the resulting files to your email. That report includes your app and OS version plus the current session state, which makes most problems far quicker to track down.

Common questions

Which files does it read? Video files recorded by a vehicle's Performance Data Recorder, which carry telemetry alongside the video, plus GPX track maps. It reads only the telemetry portion of a recording, so opening a session over a network share doesn't pull the whole video across.

A file shows a warning icon. Tap the icon for the specific reason. The most common cause is a copy that was interrupted partway — recopy it from the source card rather than trusting the partial copy.

Does AI coaching send my data anywhere? Only if you turn it on and choose a cloud provider, and then only a small summary of derived numbers — never your video or GPS coordinates. On-device options send nothing at all. See the privacy policy for specifics.
